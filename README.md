# محمد مهدي طقش | Mohammad Mahdi Takach — Mahdi Media Pro Website

الموقع الرسمي ومعرض الأعمال التفاعلي لـ **محمد مهدي طقش (Mahdi Media Pro)** — مصور فوتوغرافي، مصور ومونتير فيديو، ومصمم غرافيك.

## المميزات الرئيسية (Key Features)
- **ثنائي اللغة بالكامل (عربي / English):** تبديل فوري للنصوص واتجاه الواجهة (`RTL` / `LTR`) مع حفظ تفضيل الزائر.
- **قسم الأعمال المميزة (Featured Works):** بطاقات تفاعلية في الصفحة الرئيسية مع فلترة حسب الاختصاص (تقارير تلفزيونية، بودكاست، توثيق، تصميم غرافيكي) + إمكانية إضافة أعمال مميزة جديدة بسهولة.
- **خانة معرض الأعمال المزدوجة (Dedicated Dual Portfolio Vault):** دمج مجلدي Google Drive الرسميين ([My WORK](https://drive.google.com/drive/folders/1vRzDhx01ktw4y4p_fqv-AcFg-RI4ekvu?usp=drive_link) و[CV Portfolio](https://drive.google.com/drive/folders/16FWoGru920L5Le86opUpWNt2pXbPH2Zd?usp=sharing)) بالإضافة إلى حسابات إنستغرام.
- **حاسبة التكلفة التقريبية التفاعلية (Approximate Price Estimator):**
  - تدعم اختيار الباقات الشهرية (`Starter $150`, `Standard $400`, `Growth $700`) والخدمات الفردية بالقطعة (`À La Carte`) وخدمات التصميم الطباعي والرقمي الـ 12.
  - تعرض **التكلفة التقريبية المبدئية** مع تنويه واضح بأن السعر النهائي يُحدد بالنقاش المباشر.
  - تُنشئ رسالة مفصلة تلقائياً تتضمن كافة الخدمات المختارة، مع توجيه مزدوج:
    1. **واتساب (`+961 81 947 685`):** للاستفسار السريع والأعمال البسيطة.
    2. **البريد الإلكتروني الرسمي (`mhmdmahditakach@gmail.com`):** للأعمال الاحترافية الرسمية والشركات.
- **أداة الفواتير الخاصة بالمالك (`admin/invoice-generator.html`):** مفصولة تماماً عن واجهة العميل العامة، ومصممة على طراز فاتورتك الخاصة لإصدار فواتير PDF للعملاء بعد انتهاء المشاريع.

## هيكلة المشروع (Project Structure)
```text

├── index.html                   # الصفحة الرئيسية التفاعلية للعملاء

│   └── styles.css               # التنسيقات والهوية البصرية (الداكن والذهبي)

│   └── docs/                    # ملف السيرة الذاتية وملف التسعيرة PDF
├── admin/

└── README.md                    # دليل الاستخدام والنشر على GitHub Pages
```

## خطوات النشر المجاني على GitHub Pages
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub (مثلاً باسم `mahdi-media-portfolio`).
2. ارفع جميع ملفات ومجلدات هذا المشروع إلى المستودع.
3. ادخل إلى إعدادات المستودع **Settings** ثم اختر **Pages** من القائمة الجانبية.
4. تحت قسم **Build and deployment**، اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. خلال دقيقة واحدة سيصبح موقعك متاحاً على الرابط الرسمي الخاص بك!
